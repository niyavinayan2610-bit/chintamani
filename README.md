### Project Description

Chindhamani is a fun web-based overthinking machine that takes small everyday problems and turns them into dramatic and unnecessarily complicated conclusions. Users enter a problem and receive a humorous overthinking verdict in a Malayalam-English style.

### The Problem (that doesn't exist)

People have tiny problems every day, but somehow manage to overthink them like they are life-changing decisions.

“Should I reply with 👍 or 👍👍?”
“My friend saw my message but didn't reply.”
“Which samosa should I eat first?”

These completely unnecessary situations deserve completely unnecessary levels of analysis.

### The Solution (that nobody asked for)

Chindhamani does the overthinking for you.

Enter your tiny problem, start the machine, and let Chindhamani explore every possible angle, unnecessary worst-case scenario, and dramatic conclusion before giving you a beautifully over-engineered verdict.
