# [Chindhamani] 🎯


## Basic Details



### Team Members
- Team Lead: [Niya Vinayan] - [Jain Deemed to be University]


### Project Description
[Chindhamani is a fun web-based overthinking machine that takes small everyday problems and turns them into dramatic and unnecessarily complicated conclusions. Users enter a problem and receive a humorous overthinking verdict in a Malayalam-English style.]

### The Problem (that doesn't exist)
[People have tiny problems every day, but somehow manage to overthink them like they are life-changing decisions.]

### The Solution (that nobody asked for)
[“So, Chindhamani doesn't solve your problems.
It makes them unnecessarily complicated.]

### Implementation
For Software:
HTML is used to create the structure of the web application.
CSS is used for the user interface, layout and visual styling.
JavaScript handles user interaction and the overthinking logic.
The user enters a problem and the application generates a dramatic and humorous verdict.
